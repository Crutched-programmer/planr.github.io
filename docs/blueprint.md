# **App Name**: StudyZen

## Core Features:

- Data Collection: Collect user data: age, class, curriculum, exam date, commitments, school schedule, sleep preferences.
- Plan Generation: Generative-AI-powered study plan generation tool: Using the user's data, creates an optimal study plan, with study blocks, short breaks, commitment blocks and at least 8 hours of sleep. 
- Plan Display: Displays the generated study plan in a clear format (visual calendar).
- Manual Adjustment: Allow users to make manual adjustments to their schedule.
- Profile Saving: Persistent data: Remember user preferences for repeat plan generation.

## Style Guidelines:

- Primary color: Soft lavender (#D0B8FF) to evoke a sense of calm and focus, inspired by the concept of a peaceful study environment.
- Background color: Light gray (#F0F0F4), desaturated from the primary color to maintain the relaxing theme without overwhelming the senses. This aligns with the light color scheme.
- Accent color: Muted blue (#A0C4FF), an analogous color that provides a gentle contrast. It's less saturated and lighter, ensuring it complements rather than distracts.
- Body and headline font: 'PT Sans' sans-serif. Use PT Sans for a modern yet approachable aesthetic, well-suited for both headings and body text. 
- Use simple, line-based icons to represent different subjects, commitments, and break types.
- Calendar-style layout with clear visual distinctions between study blocks, breaks, and commitments.
- Smooth transitions when switching between days or weeks in the study plan.
